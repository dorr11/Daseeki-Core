# Daseeki-Core bundled fonts

`FiraSansCondensed-Medium.ttf` — Fira Sans Condensed (Medium weight). Bundled as the
suite's default typeface so a readable face is guaranteed without any other addon.

Licensed under the SIL Open Font License, Version 1.1. The full license and copyright
notice ship alongside the font in `OFL.txt` (this directory).

The font is only *referenced* by the addon at runtime (WoW loads the `.ttf` by path);
it is redistributed unmodified under the OFL, which permits bundling with software.
